Olá! Esse projeto foi desenvolvido em conjunto entre Alunos do curso de Ciência da Computação, na materia de Interação-Homem-Computador.

O desenvolvimento do projeto foi pensado em uma ferramenta útil para o dia a dia e que tivesse acessibilidade como um dos principais pilares.

Ao longo das aulas aprendemos a desenvolver baseado em HTML e como o CSS e o JavaScript poderiam elevar o nível do projeto através do design e funcionalidades, respectivamente.

Além disso, para a otimização da criação do projeto, utilizamos o Framework BootStrap para o design, funcionalidade e também a criação do gráfico.

O projeto no momento atual (08/11/2026), ainda está em fase final de desenvolvimento e alguns ajustes pontuais ainda podem aparecer. Porém a base do projeto já está 100% consolidada.
